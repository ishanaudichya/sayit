# SayIt

Hold **Fn**, speak, release — your words land at the cursor in whatever app you're using. A Wispr Flow-style dictation app for macOS, fully on-device.

## Install (no build needed)

Grab the latest `SayIt-*.zip` from [Releases](../../releases), unzip, drag **SayIt.app** into `/Applications`, and launch. macOS will flag the unsigned download once — approve it in **System Settings → Privacy & Security → Open Anyway** (or run `xattr -dr com.apple.quarantine /Applications/SayIt.app`). Requires macOS 26+ on Apple Silicon.

- **STT:** Apple's `SpeechAnalyzer` / `SpeechTranscriber` (macOS 26+) — the engine behind system dictation. Streams partial results *while you hold the key*, so text appears almost instantly on release.
- **Smart formatting:** Apple's on-device Foundation Model (requires Apple Intelligence) removes filler words, applies self-corrections ("at 3 — no wait, 4"), and honors "new line"/"new paragraph". Cleanup runs inside a strict time budget (≤2.5s, usually far less); the raw transcript pastes if the model is slow. Toggleable in Settings.
- **Insertion:** clipboard swap + synthesized ⌘V (previous clipboard is restored).
- **UI:** menu bar agent + a floating non-activating black pill with a live waveform. Close the window anytime — dictation keeps working.

## Requirements

- macOS 26 (Tahoe) or later, Apple Silicon
- Xcode 26+
- [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`)

## Build & run

```sh
xcodegen generate
xcodebuild -project SayIt.xcodeproj -scheme SayIt -configuration Debug -derivedDataPath build build
open build/Build/Products/Debug/SayIt.app
```

Or open `SayIt.xcodeproj` in Xcode and hit Run.

## First-run setup (the app walks you through this)

1. **Microphone** — allow when prompted.
2. **Accessibility** — System Settings → Privacy & Security → Accessibility → enable SayIt. Needed to detect the Fn key globally and to type text for you.
3. **Free up the Fn key** — System Settings → Keyboard → “Press 🌐 key to” → **Do Nothing**, so macOS's own dictation/emoji picker doesn't fight SayIt.

Then click into any text field, hold **Fn**, talk, release.

## Design system — "Ink & Citron"

Adaptive light + dark: warm paper surfaces in light mode, warm ink in dark, bone/ink type, hairline strokes, and a single signal color (citron; olive as its text-accent in light) reserved for voice and primary action. Appearance is switchable in Settings (System / Light / Dark). Tokens and components live in `Sources/SayIt/DesignSystem/` (`Theme.swift`, `Components.swift`).

The app is a proper shell: **Home** (stats, recent dictations), **History** (searchable, copy/delete), **Dictionary** (spelling preferences + text replacements, wired into the dictation pipeline), **Try it** (scratchpad + demo phrases), and **Settings** — with spring-animated navigation throughout.

- **Sound design**: SayIt's UI sounds are synthesized from scratch — pitch-swept "flicks" for Fn down/up, a two-note blip on insert, a low knock on error. Regenerate with `swift scripts/make_sounds.swift`.
- **App icon**: generated by `swift scripts/make_icon.swift` (citron wave mark on ink).
- **Haptics**: trackpad taps on press/release (toggleable, like sounds, in Settings).
- **Onboarding**: five-step first-run flow with live permission detection; re-run it anytime from Settings → "Run setup again".

## Dev notes

- The project is ad-hoc signed (`CODE_SIGN_IDENTITY=-`). macOS ties Accessibility permission to the binary's signature, so **after each rebuild you may need to re-toggle SayIt in the Accessibility list**. Signing with a real Apple Development certificate (set your team in Xcode) makes the grant stick.
- Not sandboxed by design — synthetic keystrokes and global event monitors are incompatible with the App Store sandbox. Distribution will be notarized direct download.
- **Releasing**: `scripts/release.sh 0.3.0` — builds Release locally (no CI minutes), signs (Developer ID if present, else ad-hoc), zips, commits the version bump, tags `v0.3.0`, pushes, and publishes a GitHub Release with install notes. With an Apple Developer account ($99/yr), the script picks up your Developer ID automatically; add notarization (commented inside) for a warning-free install experience.
- Roadmap: punctuation style settings → per-app tone profiles → raw-vs-cleaned diff view in History.
